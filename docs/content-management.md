# 글과 이미지 관리

글은 `_posts/연도/YYYY-MM-DD-제목.md`, 이미지는 `assets/images/posts/연도/글고유ID/내용해시.확장자`에 저장합니다. 프로필 사진은 `assets/images/profile/`에 따로 저장합니다.

- 관리자 글쓰기로 등록하면 경로를 자동 지정합니다.
- `post_id`, `image_year`, 최초 작성일과 `permalink`는 수정해도 유지됩니다. 제목이나 Series를 바꿔도 폴더가 바뀌지 않습니다.
- 같은 글에서 같은 이미지 파일을 반복 첨부해도 내용 해시가 같으면 파일 하나만 저장합니다.
- PNG는 원래 해상도와 PNG 픽셀 데이터를 그대로 두고 압축 및 불필요한 텍스트 메타데이터 제거만 합니다. 압축 결과가 더 클 때는 원본을 유지합니다.
- JPG는 해상도를 유지한 WebP 품질 92로 변환하되 더 작을 때만 사용합니다. 이 변환은 손실 압축입니다.
- GIF, WebP, APNG는 애니메이션을 보존하기 위해 원본을 유지합니다.
- 이미지 선택과 미리보기는 GitHub에 저장하지 않습니다. 게시/수정 저장 때만 반영합니다.

## 점검

저장소 루트에서 `python3 tools/content_audit.py`를 실행하면 글·이미지 수, 용량, 미사용 후보, 중복 파일을 확인할 수 있습니다. `--check`는 끊어진 이미지 경로나 잘못된 글 폴더가 있으면 실패하며 배포 CI에서도 실행합니다.

미사용 후보는 바로 삭제하지 않습니다. 다른 사이트의 링크와 브라우저에만 있는 미게시 초안까지는 검사할 수 없으므로 목록을 보고 확인해야 합니다. 글을 삭제해도 이미지 파일은 자동 삭제하지 않습니다.

## 기존 자료 이동

2026년 9월 정리에서 기존 글 URL은 `permalink`로 고정했고, `_data/content_moves.json`에 이전 글·이미지 경로와 새 경로를 기록했습니다. 관리자 화면은 예전 수정 주소와 로컬 초안 경로를 자동 변환합니다. 글 본문 내 이미지 참조는 새 위치로 변경했습니다. GitHub 원본 파일 주소와 예전 업로드 파일의 직접 주소는 이동으로 변경됩니다.

이번 정리는 현재 파일 구성을 줄이는 작업입니다. 이전 이미지 데이터는 Git 커밋 기록에 남으므로 전체 Git 기록의 용량을 줄이기 위한 강제 이력 재작성은 하지 않습니다.
